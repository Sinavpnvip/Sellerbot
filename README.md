# 🛒 PasarGuard Shop Bot

ربات فروش کامل و سبک برای پنل **JinX / PasarGuard**

- دیپلوی خیلی ساده روی Railway (فقط لینک گیت‌هاب)
- تقریباً همه تنظیمات از داخل خود ربات (پنل ادمین تلگرام)
- کیف پول + رسید کارت
- ساخت خودکار اکانت در پنل
- پلن‌های قابل مدیریت
- سیستم دعوت دوستان
- آمار فروش

---

## دیپلوی روی Railway (۳ دقیقه)

### ۱. ساخت ربات تلگرام
1. برو به [@BotFather](https://t.me/BotFather)
2. `/newbot` بزن و اسم و یوزرنیم بده
3. توکن را کپی کن

### ۲. گرفتن آیدی عددی خودت
برو به [@userinfobot](https://t.me/userinfobot) و آیدی عددی‌ات را بگیر.

### ۳. دیپلوی
1. این ریپو را **Fork** کن (یا مستقیم Deploy from GitHub بزن)
2. در Railway → New Project → Deploy from GitHub repo
3. ریپوی فورک‌شده را انتخاب کن
4. در **Variables** این دو تا را اضافه کن:

| متغیر       | مقدار                          |
|-------------|--------------------------------|
| `BOT_TOKEN` | توکن ربات از BotFather         |
| `ADMIN_IDS` | آیدی عددی خودت (مثال: 123456789) |

5. یک **Volume** اضافه کن با مسیر:
   ```
   /app/data
   ```
6. **Generate Domain** بزن (اختیاری ولی بهتر است)
7. صبر کن تا Deploy موفق شود.

### ۴. تنظیم داخل ربات
1. در تلگرام به ربات `/start` بزن
2. دکمه **⚙️ پنل مدیریت** را بزن
3. **🔗 اتصال به پنل JinX** را بزن و آدرس + یوزر + پسورد پنل را بده
4. **📦 مدیریت پلن‌ها** → پلن‌های فروش را اضافه کن
5. **💳 تنظیمات کارت** → شماره کارت و نام صاحب حساب را بگذار

تمام! ربات آماده فروش است.

## امکانات

### کاربر
- خرید اشتراک با موجودی کیف پول
- شارژ کیف پول با ارسال رسید کارت
- مشاهده اشتراک‌های خریداری‌شده + لینک ساب
- سیستم دعوت دوستان (درصد قابل تنظیم)
- اکانت تست (قابل فعال/غیرفعال)

### ادمین (داخل تلگرام)
- اتصال به پنل JinX / PasarGuard با تست اتصال
- مدیریت کامل پلن‌ها (افزودن / حذف)
- تأیید یا رد رسیدهای واریز
- تنظیم شماره کارت، حداقل واریز، متن خوش‌آمد و پشتیبانی
- آمار تعداد کاربران و مجموع فروش

## نکات مهم

- حتماً Volume روی `/app/data` بگذار تا دیتابیس با ری‌استارت پاک نشود.
- اگر چند ادمین می‌خواهی: `ADMIN_IDS=111,222,333`
- پنل باید از بیرون در دسترس باشد (آدرس Railway پنل JinX).
- اگر ساخت اکانت در پنل خطا داد، یوزرنیم/پسورد ادمین پنل و دسترسی API را چک کن.
