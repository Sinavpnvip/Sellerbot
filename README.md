# 🛒 PasarGuard Shop Bot (نسخه پیشرفته)

ربات فروش کامل برای پنل **JinX / PasarGuard** با امکانات حرفه‌ای

## امکانات نسخه جدید

### کاربر
- خرید اشتراک + کیف پول + رسید کارت
- **کد تخفیف** (از پنل ادمین ساخته می‌شود)
- **اکانت تست واقعی** (یک‌بار برای هر کاربر)
- انتخاب و مشاهده اشتراک‌ها
- سیستم دعوت دوستان با درصد قابل تنظیم
- پروفایل و موجودی

### ادمین (داخل تلگرام)
- اتصال و تست پنل JinX
- مدیریت پلن‌ها
- **ساخت / حذف کد تخفیف** (درصدی یا مبلغی + سقف استفاده)
- **جستجو و مدیریت کاربران** (تغییر/افزایش موجودی، مسدود/رفع مسدود)
- تأیید/رد رسید واریز
- **پیام همگانی** به همه کاربران
- تنظیم درصد دعوت دوستان
- تنظیم اکانت تست (روز و حجم)
- کانال اجباری عضویت
- تنظیم متن‌ها و کارت بانکی
- آمار فروش و کاربران

---

## دیپلوی Railway

1. این پوشه را در گیت‌هاب آپلود کنید
2. Railway → Deploy from GitHub
3. Variables:
   - `BOT_TOKEN` = توکن ربات
   - `ADMIN_IDS` = آیدی عددی ادمین (چندتا با کاما)
4. Volume با مسیر `/app/data`
5. Deploy

بعد از بالا آمدن:
- `/start` → پنل مدیریت
- اتصال پنل + پلن + کارت + کد تخفیف
